# Ambient Granulator for 3DS v0.12

This release adds an unattended kiosk mode that evolves the frozen granular
texture over time and yields permanently to the first recognized human input.

## Highlights

- `KIOSK MODE` is displayed over the waveform while unattended operation is
  active.
- After each newly randomized 30–60 second dwell, the app loads a different
  random sample, turns Freeze off, selects a different pitch from -12, -7, 0,
  +7 or +12 semitones, and plays the configured grain count.
- Freeze returns only after the complete burst has launched and its active
  voices have finished, preserving a fully excited texture.
- The first recognized button press or release, touchscreen gesture, Circle
  Pad direction, or C-stick direction permanently disables kiosk mode for the
  current run and cancels any pending automatic Freeze action.
- Sample switching, the unfrozen effects configuration, and burst triggering
  are published atomically to the audio worker so no new burst can begin
  against a stale frozen configuration.
- Dedicated host tests cover randomized interval bounds, non-repeating sample
  and pitch choices, burst completion, Freeze sequencing, and permanent input
  cancellation.

## Download

Most users should download `ambient-granulator-for-3DS-v0.12-sd.zip`, extract
it, and merge its `3ds` folder into the root of the console SD card. The direct
`.3dsx` binary is also provided for manual installs and browser patching.

The release retains the five-source-sample CC0 pack as
`ambient-granulator-for-3DS-v0.12-cc0-samples.zip` and includes
`SHA256SUMS.txt` for artifact verification.

If `/3ds/3ds-granulator/sample_bank.bin` already exists on the SD card, remove
it or replace it with the current bank because that file overrides samples
embedded in the application.

## Requirements

- A Nintendo 3DS-family system able to run Homebrew Launcher applications.
- DSP firmware configured through the maintained 3DS Hacks Guide setup process.
- Headphones are recommended when recording to avoid punching speaker output
  back into the console microphone.

## Known limitations

- OSC networking and camera-driven control are planned but not included.
- No CIA package is provided.
- Emulator microphone routing and latency are not authoritative; physical
  hardware remains the reference for microphone and timing behaviour.
