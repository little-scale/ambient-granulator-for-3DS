# Ambient Granulator for 3DS v0.11

This release starts in motion: it chooses a random sample, launches the
configured eight-grain burst, lets the complete burst excite the reverb, and
then enables Freeze automatically to hold the resulting texture.

## Highlights

- A different randomly selected bank sample and grain pattern on each launch.
- Automatic eight-grain startup burst with correctly sequenced Freeze
  activation, avoiding an empty frozen reverb.
- Five newly embedded piano samples at 48 kHz mono PCM16.
- The five original WAV files are published in the repository and the
  `cc0-samples.zip` release asset under CC0 1.0 Universal.
- The bank builder now discovers and naturally sorts the WAV files in
  `samples/`, so future sample-set replacements do not require a hard-coded
  filename list.

## Download

Most users should download `ambient-granulator-for-3DS-v0.11-sd.zip`, extract
it, and merge its `3ds` folder into the root of the console SD card. The direct
`.3dsx` binary is also provided for manual installs and browser patching.

Download `ambient-granulator-for-3DS-v0.11-cc0-samples.zip` for the five
original source WAV files together with their CC0 dedication and legal code.
The release includes `SHA256SUMS.txt` for artifact verification.

If `/3ds/3ds-granulator/sample_bank.bin` already exists on the SD card, remove
it or replace it with the new bank because that file overrides samples embedded
in the application.

## Requirements

- A Nintendo 3DS-family system able to run Homebrew Launcher applications.
- DSP firmware configured through the maintained 3DS Hacks Guide setup process.
- Headphones are recommended when recording to avoid punching speaker output
  back into the console microphone.

## Known limitations

- OSC networking and camera-driven control are planned but not included.
- No CIA package is provided.
- Emulator microphone routing and latency are not authoritative; physical
  hardware remains the reference for microphone and timing behaviour.
